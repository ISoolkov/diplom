# АИС «Студенческий совет» (MUIV)

Веб-приложение на Django для информационного сопровождения деятельности студсовета: новости, мероприятия, документы, обратная связь, личный кабинет, соцсеть и staff-панель.

## Русская версия

### 1. Что установить перед первым запуском

1. Python 3.9+  
2. Зависимости из requirements.txt

### 2. Первый запуск проекта (Windows, PowerShell)

# 1 Клонировать проект
git clone <URL_репозитория>
cd diplom

# 2 Создать и активировать виртуальное окружение
python -m venv venv
.\venv\Scripts\activate

# 3 Установить зависимости
pip install -r requirements.txt

# 4 Перейти в папку Django-проекта
cd myproject

# 5 Применить миграции
python manage.py migrate

# 6 (Рекомендуется) Загрузить демо-данные и демо-пользователей
python manage.py seed_demo_data

# 7 Запустить сервер
python manage.py runserver

Сайт откроется по адресу: http://127.0.0.1:8000/

### 4. Как пользоваться сайтом по ролям

#### Студент

- Просматривает публичные разделы: главная, новости, мероприятия, документы, FAQ, проекты, галерея.  
- Регистрируется и входит в систему.  
- Подает обращения через форму обратной связи.  
- Подает заявку на вступление в студсовет.  
- Записывается на мероприятия (с учетом дедлайна и лимита мест).  
- Пользуется личным кабинетом: профиль, мои обращения, мои заявки, мои мероприятия, файлы.  
- В разделе «Соцсеть» может комментировать публикации и закреплять посты только для себя.

#### Менеджер

- Имеет доступ к staff-панели (/staff/).  
- Модерирует обращения и заявки.  
- Редактирует анонсы мероприятий в разделе /events/ (включая дедлайн и максимум участников).  
- Публикует посты в соцсети, может глобально закреплять/откреплять посты.  
- Формирует и скачивает отчеты DOCX/XLSX.

#### Админ

- Имеет все права менеджера.  
- Дополнительно управляет пользователями и ролями.  
- Имеет расширенные права на управление файлами и системными разделами.

### 6. Структура проекта (кратко)

- myproject/core/views/public_views.py — публичные страницы  
- myproject/core/views/cabinet_views.py — личный кабинет  
- myproject/core/views/staff_views.py — staff-раздел  
- myproject/core/services/ — бизнес-логика (регистрация на мероприятия, модерация, отчеты)  
- myproject/templates/ — HTML-шаблоны  
- myproject/static/ — стили, изображения, документы, скрипты
