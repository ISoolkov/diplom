# АИС «Студенческий совет» (MUIV)

Веб-приложение на Django для информационного сопровождения деятельности студсовета: новости, мероприятия, документы, обратная связь, личный кабинет, соцсеть и staff-панель.

## Русская версия

### 1. Что установить перед первым запуском

1. Python 3.9+
2. Зависимости из `requirements.txt`

### 2. Первый запуск проекта (Windows, PowerShell)

```powershell
# 1) Клонировать проект
git clone <URL_репозитория>
cd diplom

# 2) Создать и активировать виртуальное окружение
python -m venv venv
.\venv\Scripts\activate

# 3) Установить зависимости
pip install -r requirements.txt

# 4) Перейти в папку Django-проекта
cd myproject

# 5) Применить миграции
python manage.py migrate

# 6) (Рекомендуется) Загрузить демо-данные и демо-пользователей
python manage.py seed_demo_data

# 7) Запустить сервер
python manage.py runserver
```

Сайт откроется по адресу: `http://127.0.0.1:8000/`

### 3. Демо-пользователи (после `seed_demo_data`)

- `admin_demo` / `AdminDemo123!`
- `manager_demo` / `ManagerDemo123!`
- `student_demo` / `StudentDemo123!`

### 4. Как пользоваться сайтом по ролям

#### Студент

- Просматривает публичные разделы: главная, новости, мероприятия, документы, FAQ, проекты, галерея.
- Регистрируется и входит в систему.
- Подает обращения через форму обратной связи.
- Подает заявку на вступление в студсовет.
- Записывается на мероприятия (с учетом дедлайна и лимита мест).
- Пользуется личным кабинетом: профиль, мои обращения, мои заявки, мои мероприятия, ответы модератора, файлы.
- В разделе «Соцсеть» может комментировать публикации и закреплять посты только для себя.

#### Менеджер

- Имеет доступ к staff-панели (`/staff/`).
- Модерирует обращения и заявки.
- Редактирует анонсы мероприятий в разделе `/events/` (включая дедлайн и максимум участников).
- Публикует посты в соцсети, может глобально закреплять/откреплять посты.
- Формирует и скачивает отчеты DOCX/XLSX.
- Управляет FAQ: добавляет, удаляет, меняет порядок.

#### Админ

- Имеет все права менеджера.
- Дополнительно управляет пользователями и ролями.
- Имеет расширенные права на управление файлами и системными разделами.
- Может включать режим техобслуживания.
- Видит логи активности.
- Использует 2FA (Google Authenticator/TOTP).

### 6. Структура проекта (кратко)

- `myproject/core/views/public_views.py` — публичные страницы
- `myproject/core/views/cabinet_views.py` — личный кабинет
- `myproject/core/views/staff_views.py` — staff-раздел
- `myproject/core/services/` — бизнес-логика (регистрация на мероприятия, модерация, отчеты, уведомления)
- `myproject/templates/` — HTML-шаблоны
- `myproject/static/` — стили, изображения, документы, скрипты

## 7. Актуальные обновления проекта

- Темы интерфейса: светлая/темная.
- Версия для слабовидящих (высокая контрастность).
- Раздел «Опросы» (создание админ/менеджер, голосование авторизованных).
- Раздел «Соцсеть» доступен только авторизованным.
- Вложения в обращениях и в ответах модератора.
- Антиспам для форм: не чаще 1 раза в минуту.
- Удаление мероприятий для админа и менеджера в `/events/`.
- Подсветка просроченных обращений/заявок (>48 ч без ответа).
- SLA-индикатор в staff: «Без ответа: N ч».
- Фильтр «Только просроченные» в разделах staff:
  - Обращения
  - Заявки
- Авто-напоминания за 24 часа до мероприятия для зарегистрированных.
- Тестовая отправка email из staff-панели.

### 7.1 Настройка email (SMTP)

```powershell
$env:EMAIL_HOST="smtp.yandex.ru"
$env:EMAIL_PORT="465"
$env:EMAIL_USE_SSL="1"
$env:EMAIL_USE_TLS="0"
$env:EMAIL_HOST_USER="your_mail@yandex.ru"
$env:EMAIL_HOST_PASSWORD="your_app_password"
$env:DEFAULT_FROM_EMAIL="your_mail@yandex.ru"
```

Для Яндекса используйте пароль приложения.

### 7.2 Тест отправки без SMTP (в файл)

```powershell
$env:EMAIL_BACKEND="django.core.mail.backends.filebased.EmailBackend"
$env:EMAIL_FILE_PATH="c:\Users\User\Desktop\diplom\diplom\mail_outbox"
```

После отправки письма появятся в папке `mail_outbox` в формате `.log`.

### 7.3 Если видите ошибку про миграции

Если при запуске есть сообщение `You have unapplied migration(s)`, выполните:

```powershell
python manage.py migrate
```
